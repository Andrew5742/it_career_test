# Audio Prompt For Gemini

Create a 35-45 second seamless loop for a dark futuristic educational IT quiz. Style: cyber ambient, soft synthwave, light digital pulse, modern university technology vibe. Mood: focused, exciting, not aggressive, suitable for teenagers. No vocals, no copyrighted melodies, no harsh bass, no sudden loud sounds. It should work quietly in the background during a quiz on mobile devices.

Save or replace the generated file as:

```text
public/audio/before-the-clock-stops.mp3
```

The quiz uses the file only on the teacher/host device, loops it, and keeps the default volume low.
